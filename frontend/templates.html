Digital Signage Templates

Ready-made screens you fill in rather than build: menu boards, meeting room signs, KPI tiles, leaderboards, Wi-Fi QR codes, world clocks and more. Connect one to a Google Sheet, an API, an RSS feed or a calendar and it keeps itself up to date.

New templates are published to the signed catalog all the time, and every ScreenTinker server picks them up on its own, with no upgrade needed. This page shows the catalog as it is today.

The template library is browsed from inside ScreenTinker: sign in and open Templates to see every template in the catalog, preview it with your own text and data, and put it on a screen.

How the templates work

Fill in fields, not code

Every template comes with a form: a headline, a logo, colours, the cities for a world clock, the network name and password for a Wi-Fi sign. Slide templates are layouts with no code in them. Code templates are small web apps (animated weather, a leaderboard with moving bars, an arcade game). Both go into playlists, layouts and schedules like any other content.

Live data from the tools you already use

Templates read from ScreenTinker's built-in data sources: Google Sheets, CSV files, REST/JSON APIs, RSS and Atom feeds, iCal calendars (Google, Outlook/Exchange or any .ics link), weather, or a table you type in. Your server fetches each source on a schedule and fills the values into the template, so the screen never calls the API itself. API keys stay on the server and never reach a screen. A Google Sheet needs no Google account or API key: share it as "anyone with the link", or publish it to the web.

Keeps playing offline

A template's code, fonts and images are packed into the page itself, and players cache what they play. If the network drops, the screen keeps showing the last data it had until the connection comes back.

Signed, sandboxed, and kept up to date

The official catalog is signed, and your server checks every package against that signature before installing it. A code template runs in a sandbox: it can't see your dashboard or your account, and it can reach only the internet hosts it declared, which for most templates is none. If we ever withdraw a version, every server that checks the catalog withdraws it too.

Self-hosting?

The library is included with self-hosted ScreenTinker. It is switched off until a platform admin turns it on, and air-gapped sites can import the catalog as a signed offline bundle instead. You can also import your own templates, or contribute one to the catalog.

Frequently asked questions

Do templates cost extra?

No. Templates and data sources are on every plan, including the free plan, and in self-hosted deployments. Plans differ by screen count and storage.

Can I change a template's layout?

Each template has the fields its author exposed. For a custom layout, start from a blank slide with live data tags, or write your own code template and import it.

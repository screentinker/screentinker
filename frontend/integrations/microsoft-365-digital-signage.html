Microsoft 365 digital signage: SharePoint, OneDrive and Office files on your screens

Keep working in the tools your staff already use. A PowerPoint deck, a Word notice or an Excel sheet in OneDrive or SharePoint can play on a screen as it is, and a SharePoint folder of images and videos can feed a playlist that updates itself when someone drops in a new file.

How it works

There are two ways to use Microsoft 365 content, for two different jobs.

You want to showUseWhat it needs
A PowerPoint, Word or Excel fileCloud document widgetThe file's Embed link from Office for the web
A SharePoint or OneDrive folder of images, videos and audio, kept up to dateSharePoint & OneDrive folder syncYour organization's own Microsoft Entra app

Cloud document widget. The screen shows Microsoft's own viewer, so the file looks the way it does in Office, and edits reach the screen without re-uploading anything. Word and Excel files reload every 5 minutes by default, so a rota or a sales sheet stays current. All players can show it: Android, Fire TV, Raspberry Pi, Windows and Samsung Tizen load the page directly, and the web player (also used on BrightSign and LG webOS) frames it.

Folder sync. Point ScreenTinker at a folder and it keeps the folder's media in your content library:

  • a new file is added, like an upload
  • a changed file is replaced in place, so playlists keep it and screens fetch the new version
  • a removed file is taken out of the folder's playlist, and deleted from the library unless something else uses it

Each folder can keep a playlist of its files in file-name order. If your workspace requires approval, the updated playlist waits for review like any other change. Synced files are ordinary media, so they keep playing when the network is down.

Set it up

Show one Office file

  1. Open the file in Office for the web and choose File → Share → Embed.
  2. In ScreenTinker, open Content → Google & Microsoft documents, paste the embed code or the link inside it, and press Add document.
  3. Put the new item in a playlist and assign it to a screen.

Sync a SharePoint or OneDrive folder

  1. Register an app in your tenant (a Microsoft Entra admin, once per organization): a single-tenant app registration, with the Microsoft Graph application permission Sites.Selected (recommended: the app reads only the sites you grant it) or Files.Read.All (simpler, but it can read every file in the tenant). Grant admin consent and create a client secret.
  2. Connect it. An organization owner or admin opens Settings → Microsoft 365 and enters the tenant ID, the client ID and the secret. The connection is tested straight away.
  3. Add a folder. In SharePoint or OneDrive, choose Share → Copy link on the folder. In ScreenTinker, open Content → SharePoint & OneDrive folders, add the folder and paste the link.
  4. Syncs run every 15 minutes by default (anything from 5 to 1440). Any workspace editor can press Sync now, pause the folder or change how often it syncs.

The full walkthrough, including the Graph call that grants one site to the app, is in docs/cloud-documents.md.

Bring your own app, keep your permissions

The folder sync reads files with your organization's own Entra app, so your admins decide what it can see and can revoke it at any time. The secret is encrypted on the server and never shown again or sent to a screen. Only an organization owner or admin can add a folder, because the app may be able to read more than one workspace should see.

Media that head office plays in a corporate playlist is only updated by a sync if the folder's creator may change corporate media. Anything else is listed as an error in the sync summary and left alone.

Limits

  • A SharePoint embed needs an "anyone" link. A screen can't sign in to Microsoft, so a file only shows if it can be viewed without signing in. If your tenant doesn't allow those links, use a folder sync and export the slides as images or a video.
  • Folder sync takes media only. Images, videos and audio sync. PowerPoint, Word, Excel and PDF files in a folder are skipped and counted; show those with the Cloud document widget.
  • Up to 500 media files per folder. While a folder holds more, the sync adds and updates what it saw but removes nothing, and says so. Split a larger folder.
  • PowerPoint plays in Microsoft’s viewer. ScreenTinker sets the timing for Google Slides, but not for PowerPoint. For a deck that must advance on its own, export it as a video or images and sync it from a folder.
  • Cloud documents need the internet. The screen loads Microsoft's viewer live, so a Cloud document doesn't play offline. Synced folder media does.
  • Storage counts. Synced files count against your plan's storage, and a file larger than the server's upload limit is skipped.
  • Secrets expire. Entra client secrets have an end date. Set a reminder for the date Entra shows.

FAQ

Can I show a PowerPoint on a digital signage screen?

Yes. Open the deck in PowerPoint for the web, choose File, Share, Embed, and paste the embed code into Content → Google & Microsoft documents. The deck shows in Microsoft’s own viewer, and your edits reach the screen without re-uploading. For a deck that must advance and loop unattended, export it as a video into a synced SharePoint folder instead.

Do I need to give ScreenTinker access to our whole tenant?

No. For folder sync, use the Sites.Selected permission and grant the app only the SharePoint sites you choose. Files.Read.All also works but is much broader. A single embedded Office file needs no app at all.

Who can add a SharePoint folder?

An organization owner or admin. Once a folder is added, any workspace editor can sync it, change how often it syncs, pause it or stop syncing it.

What happens when someone deletes a file from the folder?

It is taken out of the folder’s playlist. It is also deleted from the library, unless something else uses it, such as another playlist, a schedule or a video wall.

Will it work if our tenant blocks anonymous sharing links?

Embedded Office files won’t, because a screen cannot sign in. Folder sync still works, since it reads files with your own Entra app. Export slides as images or a video into a synced folder instead.

Digital signage on ChromeOS

A Chromebox is a good sign: it boots in seconds, updates itself, and runs the player with no install at all. The only real decision is whether you manage it through the Google Admin console or set it up by hand.

Why ChromeOS is a decent signage box

The player is a web page, and ChromeOS is a browser with a machine attached. Nothing is sideloaded, nothing is signed, and the OS keeps itself patched. A managed Chromebox in kiosk mode boots straight into the sign after a power cut with no sign-in and no desktop in between — which is the single hardest thing to arrange on a general-purpose computer.

It is the same web player a browser on any other platform runs, so every feature that lives in the page — playlists, zones, layouts, schedules, widgets, proof-of-play, live view — behaves identically.

Managed kiosk, through the Admin console

This is the route to use for anything more than one screen. In the Google Admin console:

  1. Open Devices → Chrome → Apps & extensions → Kiosks.
  2. Pick the organisational unit the screens live in — not the top level, unless every device in the domain is a sign.
  3. Add by URL, and enter your instance’s player address, for example https://your-server/player. The downloads page on your instance prints the exact address.
  4. Set it as the auto-launch kiosk app for that OU.

Enrolled devices in that OU reboot into the player with no user session at all. Managed kiosk mode is a paid ChromeOS management feature — Google licenses it per device — so check that the Chromeboxes you are buying carry an upgrade, or use the unmanaged route below.

Two device settings in the same OU are worth turning on while you are there: keep the display awake on mains power, and allow the device to power on when mains power returns if the hardware supports it.

Unmanaged, on a single Chromebox

No licence, no console, five minutes:

  1. Sign in as the account the screen will run under.
  2. In Chrome settings, set On startup to open your player URL.
  3. Open the player and press F11 for fullscreen. It stays fullscreen across restarts.
  4. Under Settings → Device → Power, set the display to stay on while charging.

The difference from managed kiosk is honest and worth knowing: this session can be exited, and a reboot lands on the sign-in screen unless the account is already signed in. For a screen behind a counter that is fine. For a screen in a lobby, pay for the kiosk licence.

Pairing

The player opens on a six-digit code. In the dashboard choose Add Display, type the code, name the screen. Done.

If the Chromebox is wiped and re-enrolled it will show a new code and arrive as a new screen. To move an existing screen’s content across, assign the playlist to the new one and delete the old.

What it cannot do

Like every browser-based player: screen off is a black overlay rather than the panel actually sleeping, and reboot from the dashboard is ignored. If you need real panel power control on a schedule, that works on Android, BrightSign and LG webOS panels, where the player can reach the hardware.

Google’s own ChromeOS kiosk licensing and hardware lifecycle are worth reading before committing a fleet — a Chromebox has an auto-update expiry date, after which it stops receiving OS updates. Check that date on the model before buying twenty of them.

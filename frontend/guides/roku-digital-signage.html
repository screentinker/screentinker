ScreenTinker on Roku

A native player for Roku streaming sticks and Roku TVs. It plays your playlists, schedules and layouts well. But a Roku was built for watching TV, not for running a sign unattended, and some things it will never do. They are listed below so you can decide before you buy one.

Where it stands

  • Roku Channel Store: live. Add it to your Roku account with this link (channel code Screentinker).
  • Tested on: one Roku Streaming Stick 4K (model 3820R2) on Roku OS 15.3.4, paired to screentinker.com. It paired, played image playlists, and started in about 1.5 seconds.
  • Listed under Known issues on the certified hardware page, not as Certified Hardware. One stick is a test, not a certification, and the limits below are real.
  • The stick we tested: Roku Streaming Stick 4K (3820R2). See it on Amazon (affiliate link). As an Amazon Associate, ScreenTinker earns from qualifying purchases.

What you need

  • Roku OS 15.1 or later. Roku's store requires it for new apps, so older Rokus that cannot update to 15.1 cannot install it. Check under Settings > System > About.
  • A ScreenTinker server newer than 2.5.1. The Roku support is in the server as well as the app. If you self-host, the server also needs Chromium installed to draw web content for the Roku (see Web content is a picture below).
  • A ScreenTinker account, on screentinker.com or your own server.

Setting it up

  1. Add ScreenTinker to the Roku account the device is signed into: open my.roku.com/account/add/Screentinker and sign in. It installs on that account's Rokus within a day, or at once from Settings > System > System update > Check now. You can also find it by searching the Roku Channel Store for ScreenTinker.
  2. Open it. Keep https://screentinker.com, or type your own server's address, then choose Connect. You can change the server later with the options (*) key.
  3. A pairing code appears. In your dashboard, add a display and enter the code.
  4. Change these Roku settings, or the sign will not last the day:
    • Settings > Theme > Screensaver: set the wait time to the longest it offers, or off if your model allows it.
    • Settings > System > Power: turn off Auto power saving. Turn off Bandwidth saver under Settings > Network.
    • If Autoplay is off on the Roku, the player waits for someone to press OK after each launch. That is a Roku rule, and the screen says so.

What it plays

  • Images, and video up to 1920 x 1080 (see the limit on tall video below).
  • Playlists, schedules, play order, and power schedules that blank the screen out of hours.
  • Layouts with several zones. A Roku decodes one video at a time, so only one zone plays video. The others show the video's thumbnail.
  • Clocks, drawn on the Roku so the seconds tick.
  • Widgets and web pages, as pictures drawn by the server (next section).

What a Roku cannot do

None of these is something we can fix in the app. They are how Roku works.

  • It does not start by itself. After a power cut, a reboot or a Roku update, the Roku goes to its home screen and stays there. Roku does not let any app start on its own. Someone has to open the app again, or an always-on device on the same network can do it with one request to Roku's network control: POST http://<roku-address>:8060/launch/<app id>, allowed under Settings > System > Advanced system settings > Control by mobile apps. ScreenTinker does not send that for you yet. If the screen must come back without anyone, use another player.
  • No remote reboot, volume, screenshots or live view. Apps cannot reboot a Roku, change its volume, or capture the screen, so the dashboard cannot show you what a Roku is displaying.
  • No control of the TV. No power on or off, and no switching inputs. Power schedules blank the picture instead.
  • Web content is a picture. A Roku has no web browser. Widgets, web pages and slides are drawn by your ScreenTinker server and sent as images, refreshed on a timer. They are correct but still: no animation, no video inside a web page, nothing to touch. A self-hosted server needs Chromium for this.
  • No tall H.264 video. A Roku cannot decode H.264 that is more than 1080 pixels tall, which rules out portrait 1080 x 1920 phone and AI clips. The size of the zone makes no difference, because decoding comes first. The screen tells you which video failed. Upload a copy no bigger than 1920 x 1080, for example: ffmpeg -i in.mp4 -vf "scale=-2:1080" -c:v libx264 -crf 20 -c:a copy out.mp4
  • The screensaver is not blocked. Roku's store rules forbid an app from keeping the screensaver away, so over still images it can start. That is why the setup step above sets its wait time to the longest.
  • No video walls or group sync. A Roku can be one screen of its own, not part of a synchronised wall.
  • No interactive kiosk. There is no touch, and the remote only moves between the player's own screens.

When to choose something else

A Roku suits a screen that someone switches on each morning: a waiting room TV, a break room, a home office. For a sign that must survive power cuts with nobody there, or that needs screenshots, reboots or live web pages, use an Android TV or Fire TV device, a Raspberry Pi, or a commercial panel.

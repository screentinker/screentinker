# ScreenTinker for LG webOS Signage

An installed shell for the ScreenTinker web player. See `docs/webos-player.md` for install,
self-update, and build details, and `vendor/README.md` for the SCAP library the build expects.

```
./build-ipk.sh            # writes ScreenTinker.ipk here
./build-ipk.sh /tmp/x.ipk # or elsewhere
```

---------------------------- DESCRIPTION -------------------------------

https://github.com/screentinker/screentinker

ScreenTinker 2.3 lets your screens read live data. Change a price in a
table, a Google Sheet or a CSV, and the menu board on the wall changes with
it - no re-publishing, no new slide.

In this release:
- Live data sources, built in on every workspace: REST API, Google Sheets,
  CSV, RSS/Atom and a manual table, alongside Calendar and Weather.
- Key columns: point at the latte's price by name, so a sorted sheet never
  puts the wrong price on screen.
- Careful by default: API credentials encrypted and never read back, an
  unshared Sheet explained instead of cached, every source scoped to its
  workspace.
- A template library: menu boards, leaderboards, KPI dashboards, meeting
  room signs, world clocks, guest Wi-Fi, event countdowns and more - fill in
  the fields or bind them to live data.
- A signed catalog: every template and the index are Ed25519-signed, with a
  serial number and revocation. Code templates run sandboxed.
- UPTIME 3036: a real first-person arcade game shipped as a template. It
  plays itself in attract mode until someone picks up the keyboard. MIT
  licensed, generated entirely in code - a starting point for your own.
- Native players for Raspberry Pi and Windows, served by your own server and
  updated only when the checksum matches.
- A Platform area for server operators: an overview with expandable
  "needs your attention" items, user and organization search, whole-
  organization members, stale-account cleanup that sends a notice first, and
  limited-time sales backed by real Stripe coupons.
- A new look with the sidebar grouped by job, 1 MiB upload chunks for slow
  links, add-content folders fixed, honest proof-of-play, and four security
  fixes.

Every screen in this video is a real ScreenTinker 2.3 server with invented
demo data. The price change at the start is real: one edit to the table,
then the same template rendered again.
